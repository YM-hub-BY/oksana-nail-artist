# Oksana Nail Artist

Статическая версия портфолио Оксаны — мастера маникюра, наращивания и педикюра с опытом с 2011 года.

## Публикация на Vercel

1. Импортируйте этот репозиторий в Vercel.
2. Выберите Framework Preset: Other.
3. Оставьте Build Command пустой.
4. Укажите Output Directory: .
5. Нажмите Deploy.

Главная страница находится в index.html; изображения и интерактивные элементы уже включены в проект.
